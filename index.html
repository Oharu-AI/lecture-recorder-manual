LectureRecorder 操作説明書

講義動画をMacで画面録画し、保存結果を確認するための説明書です。初めて使う方の手順と、画面を操作するAIが守るべき判定条件を一つにまとめています。

1. このアプリでできること

LectureRecorderはmacOSの画面収録機能を使い、選んだ画面やアプリをMP4に保存する講義録画アプリです。録画中はMacのスリープを防ぎ、終了後は録画ライブラリで再生・整理できます。動画配信サイトから元の動画ファイルをダウンロードする機能ではありません。

機能使いどころ
エリア録画画面の一部分をドラッグで指定
全画面録画選んだディスプレイ全体
ウインドウ録画一つのブラウザやアプリのウインドウ
アプリ録画アプリ全体。全画面化やポップアップへの追従が必要な講義
自動追従再生開始を待って1本を録り、静止・無音で自動保存
タイマー・予約指定時間の録画、指定時刻からの開始

保存形式はMP4。内部音声、必要に応じてマイクとカーソルを含められます。録画可能かどうかは講義サイト・表示環境にも左右されるため、最初に短い試し録画をしてください。

2. インストールと初回の許可

  1. LectureRecorder-0.1.pkgをダブルクリックし、案内に従って「アプリケーション」へインストールします。
  2. 「アプリケーション」のLectureRecorderを開きます。自己署名版で開発元の警告が出た場合は、Finderでcontrolキーを押しながらアプリをクリックして「開く」を選びます。
  3. macOSの「プライバシーとセキュリティ」で画面収録を許可し、アプリを終了して開き直します。
  4. マイク録音を使う場合はマイクを許可します。SafariのWeb表示部分の自動検出を使う場合はアクセシビリティも許可します。
  5. ブラウザを10秒録画し、MP4の映像・音・再生を確認します。
初回許可の直後やmacOSを更新した後は、本番の長時間録画前に10秒の試し録画を行ってください。

3. 画面の見方

メイン画面は横長の小さなウインドウです。上段に4つの録画モードと赤いRECボタン、中段に録画対象と「一覧」、下段に自動追従・ライブラリ・最前面表示・環境設定、およびカーソル・内部音声・マイクの切り替えがあります。録画中はプレビュー、経過時間、一時停止、停止の操作に切り替わります。

対象を画面上で選ぶ際は青い点線の枠を確認します。右上のインジケータとメニューバーでも録画状態を確認できます。録画用の小画面自体は原則として録画映像から除外されます。

「ウインドウを最大化」と「講義プレイヤーを全画面表示」は別です。講義映像だけを残す場合は、プレイヤー自身の全画面ボタンを押してください。

4. 基本の録画手順

  1. 講義ページを開き、再生できる状態にします。画面が黒い、動画が0:00から進まない場合は先に解決します。
  2. 「ウインドウ」または「アプリ」などのモードを選び、対象カードの「一覧」または画面上の青い点線から対象を選びます。
  3. カーソル・内部音声・マイクの設定、保存先、空き容量を確認します。講義では通常、内部音声ON、マイクOFF、カーソルOFFです。
  4. 必要ならプレイヤー自体を全画面にし、ブラウザのタブ、通知、再生メニューが映らないことを目で確認します。
  5. RECを押して録画開始。終わったら停止ボタンを押します。録画時間を指定した場合は満了時に自動停止します。
  6. 自動で開く録画ライブラリで、ファイルの先頭と数秒後を再生します。音声と映像があり、必要な講義部分が入っていることを確認して完了です。

対象が未選択なら録画は始まらず、画面に警告が出ます。対象が閉じられた場合、同名の候補が一つだけなら開始直前に取り直し、複数なら安全のため開始しません。

5. 自動追従で講義を1本録る

対象を選んで🔁を押すと、すぐ録画を開始して「再生待ち」になります。内部音声がONなら、2秒以上続く音を再生開始の目安とし、待ち時間の先頭を保存後に切り取ります。静止と無音が設定秒数続くと1本を保存し、その判定に使った末尾部分を切ります。

1本保存すると自動追従は終了します。 次の講義では🔁を再度押してください。再生待ち中に停止した場合、講義が始まっていない待機ファイルは破棄します。

静止秒数は環境設定で5〜3600秒に変更できます。講義の途中に長い無音・静止があると早く止まるため、本番前に動画に合った値を選びます。過去の実運用では15秒を使用しましたが、アプリの新規初期値は60秒です。

開始を見分けられない場合は待機を続けるか警告します。映像が届かない、開始できないなどの失敗は画面とログで確認してください。「録画中」の表示だけで成功とは判定しません。

6. タイマー・予約・録画後の動作

メイン画面の「タイマー」で録画時間を時・分・秒ごとに指定できます。すべて0なら手動停止まで録画します。「予約する」と開始時刻を設定した場合、RECを押すと待機し、指定時刻に対象を取り直して録画を始めます。

「終了後」は「何もしない」「スリープ」「シャットダウン」から選びます。保存と必要な後処理が終わった後、画面のカウントダウン中にキャンセルできます。手動停止、アプリ終了、録画失敗では終了後の動作を実行しません。シャットダウンは確認画面があり、設定は次回起動へ持ち越されません。

実際のシャットダウンについて、2026-08-06時点の記録ではドライランのみ合格し、実シャットダウン試験は未実施です。初回の無人運転前に、在席して短時間の試験をしてください。

7. 環境設定と保存先

項目確認すること
保存先新規状態では~/Movies/LectureRecorder/。環境設定から変更可能。録画中に空きが3GBを下回ると安全停止。
ファイル名初期の接頭辞は「講義録画」。末尾に日時が付き、同名でも上書きしない。利用中の設定は別の名前に変更されている場合があります。
画質低容量、標準、高画質、省容量高画質。新規初期値は「標準」。講義の細かい文字には高画質系が向きます。
静止で自動停止通常録画では新規初期値OFF、秒数は60秒。自動追従ではこの秒数を講義の終わり判定に使います。
カーソル・内部音声・マイク新規初期値はOFF・ON・OFF。設定は次回起動にも残るため毎回確認します。
ショートカット環境設定で変更可能。実際に表示されるキーを優先します。

「省容量高画質」はHEVCを使用します。容量は映像内容で変わり、画面の数値は目安です。外付けドライブを使う場合は、録画前に接続と空き容量を確認してください。

8. 録画ライブラリで確認・整理する

📁ボタンで「録画ライブラリ」を開けます。録画後も自動で開きます。左に再生、右に一覧があり、日付・名前・録画時間で並べ替えられます。名前変更、Finderで表示、ゴミ箱へ移動、トリム、無音削除、複数ファイルの結合ができます。

トリムは範囲を選んで別ファイルに保存します。無音削除や結合も別ファイルとして保存パネルで保存先を確定します。元の録画は、編集結果の確認が済むまで残してください。

録画成功の判定: 一覧にファイルがあることに加え、先頭と数秒後を再生し、映像・音声・全画面表示・講義内容の連続性を確認します。手動シークで飛ばした録画はファイル検査に合格しても本番としては不合格です。

9. キーボードショートカット

新規状態のソース上の既定値は下表です。既存のMacでは利用者が変更した設定が優先されます。2026-08の運用記録では開始・停止・一時停止・対象選択も⌃⌥系へ変更されていました。操作前に環境設定の表示を確認し、記憶したキーを決め打ちしないでください。

操作新規状態の既定
録画開始 / 停止⌥⌘R（同じキーで切替）
一時停止 / 再開⌥⌘P
エリア / 全画面 / ウインドウ / アプリの対象選択⌥⌘1 / ⌥⌘2 / ⌥⌘3 / ⌥⌘4
自動追従⌃⌥A
録画ライブラリ⌃⌥F
環境設定⌃⌥C
最前面に表示⌃⌥Q

設定画面で「変更」を押したら次のキーが登録されます。意図しない変更を防ぐため、操作をやめる際はEscで抜けてください。

10. 他のAIが操作するときの必須手順

AIはこの節を操作契約として扱います。画面操作ができるAIでも、対象や状態を確認できなければ録画開始を保留します。座標クリックより、アプリに表示されたショートカットや明確なボタン名を使います。

録画前ゲート（Chrome講義）

  1. 講義ページを開き、動画が0:00から進むことを確認する。サイトの操作はここまでにする。
  2. ブラウザをAIが制御している場合は、録画前にその制御を解放する。デバッグ開始のバナーや通知が消えたことを通常のMac画面で確認する。録画停止まで再接続しない。
  3. 講義プレイヤー自身を全画面表示にする。ウインドウの最大化だけで合格にしない。
  4. カーソルを下部操作メニューから離す。シークバーなどが消えるまで待つ。
  5. 録画対象、内部音声ON、マイクOFF、カーソルOFF、静止秒数、保存先と空き容量を確認する。
  6. 「Chromeのタブ等がない」「デバッグ表示がない」「講義映像が画面全体」「下部操作メニューがない」の4条件を画面で確認してから録画を始める。
4条件のどれか一つでも不明、黒画面、動画が止まっている場合はRECも🔁も押さない。講義を開き直し、確認を最初からやり直します。

開始・終了後の確認

  1. 自動追従開始後は「再生待ち」から録画へ移ったこと、開始エラーが出ていないことを確認する。
  2. 1本保存したら自動追従は終了する。次の講義へ進む前にライブラリで保存ファイルを開く。
  3. 少なくとも先頭と数秒後の映像・音声・4条件を確認する。途中を手動で飛ばした場合は全尺録画として合格にしない。
  4. 失敗したときは対象、画面の警告、ログ、保存ファイルの有無を記録する。既存の正式ファイルを勝手に削除・改名・上書きしない。

AIへ渡す短い指示文

LectureRecorderで講義を録画する前に、この説明書の「10. 他のAIが操作するときの必須手順」を読んでください。アプリの実際の画面とショートカットを確認し、Chrome講義では録画前ゲート4条件をすべて確認してください。黒画面、0:00から進まない動画、デバッグバナー、シークバーがあれば開始しないでください。自動追従は1本保存で終了します。保存後は録画ライブラリで映像と音声を再生確認し、失敗や未確認を成功と報告しないでください。既存の正式録画を勝手に変更しないでください。

ローカル操作用の詳細はリポジトリのdocs/COWORK_GUIDE.mdにあります。このHTMLだけをAIへ渡す場合も、上の手順で操作前後を判定できます。

11. 困ったとき

症状最初に確認すること
対象が出ない・RECが始まらない画面収録の許可、対象の再選択、同名ウインドウの有無。許可直後はアプリを再起動。
開始後に安全停止する対象画面が表示されているか、黒画面でないか。映像が届かない場合は警告とログを確認。
音がない内部音声ONか、元動画から音が出ているか、保存ファイルを再生したか。マイク音が必要なら別途マイクを許可。
短すぎる・途中で止まる静止・無音の判定秒数と実際の講義内容を確認。手動シークがなかったかも確認。
ブラウザUIや通知が映る講義プレイヤー自体の全画面表示と録画前ゲート4条件をやり直す。
保存されない・容量が小さい保存先、3GB以上の空き容量、画面警告、ログ、ファイルの再生可否を確認。

ログは~/Library/Logs/LectureRecorder.logです。エラーの時刻、対象名、画面の警告、保存先の状態を一緒に確認してください。非0バイトの不完全ファイルは復旧の可能性があるため自動削除しない設計です。

12. 現在の制限と確認済み範囲

  • 確認済み 2時間録画、実講義の録画、音声付きMP4、録画ライブラリ、静止停止後の末尾カットについてテスト記録があります。
  • 未確認 実シャットダウンはドライランまで。4時間連続耐久と2台目ディスプレイの実機確認も、引き継ぎ記録では未完了です。
  • 突然の電源断やMacのクラッシュでは、録画中のMP4を救えない場合があります。重要な講義ほど保存後の再生を確認してください。
  • このHTMLは操作説明書です。アプリにAI用APIやコマンドライン操作機能を追加するものではありません。AIは、利用できるMac画面操作手段とアプリの実際の表示を使います。
